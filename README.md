# Code & Cash: бот бесплатного марафона

Бот проводит участников через марафон из 2 дней: условия (TikTok + заявка в закрытый канал) → приветствие и правила → день 1 (выбор ниши, задание, сдача работы) → куратор принимает работу кнопкой → день 2 → итоги → «Что такое C&C Family?» → «Как войти?».

Все тексты и картинки шагов лежат в `content.py` и папке `images/`.

## Запуск

1. `pip install -r requirements.txt`
2. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_CHAT_ID`.
3. Добавь бота администратором закрытого канала с правом «Приглашать пользователей» (иначе он не видит заявки).
4. `python bot.py`

Данные участников хранятся в json-файлах рядом с `bot.py` (в `.gitignore`, на GitHub они не попадут). Если бот хостится на сервисе с «временным диском» (Railway, Render и т.п.), подключи постоянный том, иначе после перезапуска всё сотрётся.

## Что умеет админ

| Команда | Что делает |
|---|---|
| `/edit` | Открывает панель (то же, что `/panel`). Тексты и картинки всех сообщений бота меняются во вкладке «Сообщения». |
| `/panel` | Открывает мини-приложение (кнопка «Панель» у поля ввода тоже появляется). |
| `/backup` | Присылает файлы с историей бота. Присланные обратно файлы бот загружает сам. |

Уведомления о тех, кто дошёл до конца, не приходят: все цифры и работы смотри в панели. При каждом запуске бот присылает тебе короткий отчёт, сколько данных на месте.

**Тест-режим.** В панели (вкладка «Статистика») есть переключатель и кнопка «Пройти марафон заново как участник»: твой `/start` открывает марафон без TikTok и заявки, сколько угодно раз. Твои тесты не попадают в цифры, работы и уведомления.

## Мини-приложение (панель админа)

Четыре вкладки:
- **Статистика**: сколько запустили бота, сдали работу, прошли 1 день (куратор принял работу), дошли до конца, воронка в процентах.
- **Работы**: все присланные работы с именем, username, нишей, статусом и самими файлами (фото, видео, голосовые, документы). Работы, присланные до этого обновления, здесь не появятся, они остались только в пересланных сообщениях в твоём чате.
- **Сообщения**: все сообщения, которые бот отправляет людям (приветствие, правила, задания, день 2, итоги, «Что такое C&C Family?», «Как войти?» и другие). Для каждого можно поменять текст в редакторе (жирный, курсив, ссылки, цитаты, спойлеры), заменить, добавить или убрать картинку, посмотреть результат у себя в чате («Показать мне») и вернуть стандартный вариант. Изменения действуют сразу, GitHub и обновление бота не нужны. В тексте можно использовать `{name}` (имя человека, только в приветствии) и `{contact}`, `{tg_url}`, `{reviews_url}`. Тексты кнопок и всплывающих подсказок («Я подписался» и т.п.) по-прежнему в `content.py`.
- **Рассылка**: текст всем, кто запускал бота (или только тем, кто дошёл / не дошёл до конца). Кнопка «Тест мне» шлёт сообщение только тебе. Текст набирается как в обычном редакторе: выдели слово и нажми Ж, К, Ч, З, ссылку, цитату, код или спойлер. К рассылке можно прикрепить до 10 фото (каждое до 10 МБ): одно уйдёт как фото, несколько как альбом, подпись у первого (до 1024 символов). Заблокировавшие бота пропускаются и помечаются.

Доступ только у тебя: сервер проверяет подпись Telegram и твой id, остальные получают 403.

### Как включить

Telegram открывает мини-приложения только по **https**. Нужна публичная https-ссылка, которая ведёт на порт бота (`WEBAPP_PORT`, по умолчанию 8080). Впиши её в `.env` как `WEBAPP_URL` и перезапусти бота. Варианты:

1. **Быстро проверить с компьютера:** установи `cloudflared` и запусти `cloudflared tunnel --url http://localhost:8080`. Он выдаст ссылку вида `https://что-то.trycloudflare.com`. Она меняется при каждом перезапуске туннеля.
2. **Постоянно на VPS:** домен + Caddy: `твой.домен { reverse_proxy localhost:8080 }`. Caddy сам выпустит https.
3. **Railway:** подробная инструкция ниже.

Если `WEBAPP_URL` пустой, мини-приложение просто выключено, остальной бот работает как раньше.

## Деплой на Railway (рекомендуется)

1. Залей проект в **приватный** репозиторий GitHub (данные участников в `.gitignore`, `.env` тоже).
2. Railway → **New Project → Deploy from GitHub repo** → выбери репозиторий. Запуск берётся из `Procfile` (`python bot.py`).
3. Сервис → **Variables**, добавь: `BOT_TOKEN`, `ADMIN_CHAT_ID`, `PORT=8080`. По желанию: `CONTACT_HANDLE`, `JOIN_CHAT_ID`.
4. **Постоянное хранилище.** Сервис → **Volumes** (или правый клик по сервису → Attach volume), путь монтирования `/data`. Бот сам поймёт, что данные надо хранить там. Без тома история участников стирается при каждом обновлении.
5. Сервис → **Settings → Networking → Generate Domain** (порт 8080). Получишь адрес вида `https://что-то.up.railway.app`.
6. Добавь переменную `WEBAPP_URL` с этим адресом (с `https://`, без слэша в конце), Railway перезапустит бота. В боте появятся кнопка «Панель» и команда `/panel`.
7. **Старого бота останови** (на компьютере или другом хостинге). Два запущенных бота с одним токеном мешают друг другу (ошибка Conflict).

### Перенос истории со старого места

Команда `/backup` присылает все файлы данных. Чтобы перенести историю: на старом боте (до остановки) набери `/backup`, а когда новый заработает на Railway, перешли эти файлы новому боту в личку. Каждый файл бот проверит и сразу применит. Эту же команду стоит запускать иногда как резервную копию.

## Файлы

- `bot.py`: логика марафона для участников
- `admin_panel.py`: `/edit`, `/panel`, счётчики и сервер мини-приложения
- `storage.py`: хранение данных (запись атомарная, повреждённый файл не роняет бота)
- `content.py`: тексты и кнопки, `images/`: картинки
- `webapp/`: мини-приложение (`index.html`, `logo.png`)

## Что исправлено в этой версии

- Нажатия на кнопки шагов проверяют этап участника: двойные и старые кнопки больше ничего не ломают.
- Сдача работы: принимаются альбомы из нескольких скринов, голосовые, видео и кружки. Короткая фраза вроде «сейчас пришлю» не считается работой. Если пересылка куратору не удалась, человек может отправить работу ещё раз.
- Кнопка «Открыть день 2» работает только для тех, кто сдал работу.
- Запись файлов атомарная.
- Задания: вместо «обязательно нужен VPN» теперь пояснение, что VPN нужен тем, кто в РФ, и честное предупреждение о рисках.

Таймер «24 часа на каждый день» по-прежнему не проверяется ботом, это только текст для участников.
