# Бот марафона Code & Cash

Бесплатный марафон на 2 дня. Работает целиком внутри Telegram, без сайта и без лишних переходов для участника.

## Как устроен марафон

**Старт (условия)**
1. `/start` или слово «старт» → бот показывает два условия: нажать «Перейти в TikTok» и подписаться, подать заявку в закрытый канал
2. Участник жмёт «Я подписался». Пока не выполнены оба условия, марафон не запускается
3. **Заявка в канал** проверяется по-настоящему: бот видит заявку на вступление. **TikTok** проверить технически нельзя (у TikTok нет доступа для ботов), поэтому бот проверяет другое: человек обязан нажать кнопку «Перейти в TikTok» (нажатие фиксируется, только после него бот выдаёт ссылку), и «Я подписался» сработает не раньше, чем через 15 секунд после этого нажатия (`TIKTOK_MIN_SECONDS` в `content.py`). Открыл ли человек ссылку и подписался ли, бот знать не может

**День 1**
4. Приветствие → кнопка "Стартуем"
5. Предупреждение про правила (проходится один раз, без перезапуска)
6. Выбор ниши: сайты, боты и автоматизации, или дашборды
7. Практическое задание под выбранную нишу
8. Участник присылает результат (скрин, файл, ссылку, что угодно) прямо в бота

**Проверка**
9. Работа пересылается тебе в личку. Рядом карточка участника: имя, @username, id, ссылка на профиль и кнопка «Написать участнику», чтобы сразу зайти к человеку и написать
10. Ты смотришь и жмёшь «Открыть день 2 ✅»

**После проверки (всё кнопками, по цепочке)**
11. Участнику приходит картинка + «Куратор посмотрел и всё принял 🔥» + зелёная кнопка **✅ОТКРЫВАЮ**
12. Нажал → день 2 по его нише с картинкой + синяя кнопка **🎉Итоги**
13. Нажал → «Итог марафона» (без картинки) + кнопка «Что такое C&C Family?»
14. Нажал → картинка ccfm.jpg + описание C&C Family + кнопка «Как войти?»
15. Нажал → картинка family_offer.png + информация о второй волне, контакты и ссылки

Никакого кодового слова печатать не нужно, это сделано специально, чтобы у участника было меньше лишних действий. Проверка полностью на твоей стороне через одну кнопку.

## Установка и запуск

### 1. Получить токен бота

В Telegram напиши @BotFather, команда `/newbot`, следуй инструкции, в конце получишь токен вида `123456:ABC-DEF...`

### 2. Узнать свой chat_id

Напиши в Telegram боту @userinfobot, он пришлёт твой числовой id. Это нужно, чтобы бот знал, куда пересылать работы на проверку.

### 3. Установить зависимости

```bash
pip install -U -r requirements.txt
```

Версия aiogram обновлена (нужна 3.25+), потому что цветные кнопки (зелёная и синяя) появились в Telegram Bot API позже, чем в старой версии проекта. Если раньше ставил зависимости, запусти команду с `-U`.

### 4. Настроить переменные окружения

Скопируй `.env.example` в `.env` и впиши свои значения:

```bash
cp .env.example .env
```

Открой `.env` и укажи:
- `BOT_TOKEN` — токен из шага 1
- `ADMIN_CHAT_ID` — твой id из шага 2
- `CONTACT_HANDLE` — твой контакт для связи (уже стоит @SUN9ISE)
- `JOIN_CHAT_ID` — необязательно, числовой id закрытого канала (бот определяет его сам)
- `ADMIN_BYPASS_SUBSCRIPTION` — `0`: ты при `/start` проходишь условия как все (можно проверить, как это выглядит), `1`: ты пропускаешь подписку и сразу идёшь в марафон

### 5. Сделать бота админом закрытого канала (обязательно для проверки заявок)

Telegram присылает боту заявки на вступление только если он **администратор** канала с правом **«Приглашать пользователей»**. Открой закрытый канал → Управление каналом → Администраторы → Добавить администратора → выбери своего бота и оставь включённым «Приглашать пользователей по ссылке».

Канал бот определяет сам по первой заявке, пришедшей по ссылке из `content.py` (`JOIN_REQUEST_URL`). Если хочешь, можно указать его заранее: `JOIN_CHAT_ID=-100...` в `.env`. Заявки бот **не одобряет**, это остаётся за тобой. Ссылки лежат в `content.py` (`JOIN_REQUEST_URL`, `TIKTOK_URL`, `TG_CHANNEL_URL`). Кто подал заявку, записывается в `join_requests.json`.

**Обязательно проверь:** подай заявку со второго аккаунта и пройди условия. Если бот не админ канала, он не увидит заявок и никто не пройдёт условия (в этом случае бот напишет тебе предупреждение).

### 6. Запустить

```bash
python bot.py
```

Пока этот процесс запущен, бот работает. Для локального теста этого достаточно.

## Как сделать бота рабочим 24/7

Локально бот работает, только пока у тебя открыт терминал и включён компьютер. Чтобы он работал постоянно, нужно вынести его на сервер (VPS). Коротко:

1. Арендуй недорогой VPS (от 300 рублей в месяц, любой хостинг подойдёт)
2. Залей туда эти файлы
3. Установи Python и зависимости так же, как локально
4. Запусти `python bot.py` в фоне (например через `screen`, `tmux` или `systemd`), чтобы процесс не завершался при закрытии терминала

Если что-то непонятно на этом шаге, можно попросить Claude Code прямо на сервере помочь с настройкой автозапуска, он умеет объяснить и настроить это пошагово.

## Сколько осталось мест

В `content.py` есть число `SPOTS_LEFT`. Меняй его вручную, когда места раскупаются, слово («место / места / мест») подставится само.

## Как редактировать тексты марафона

Все тексты лежат в `content.py`. Логика бота их не трогает, поэтому можно смело редактировать любые фразы, задания под ниши, финальное сообщение с предложением продукта — без риска что-то сломать в коде.

## Как редактировать картинки

Картинки лежат в папке `images/`. У каждого шага марафона своё имя файла (welcome.jpg, day1_intro.jpg, approved.jpg, day2_sites.jpg, day2_bots.jpg, day2_dashboards.jpg, ccfm.jpg, family_offer.png). Чтобы поменять картинку, загрузи новый файл с тем же именем.

Шаги после проверки (принято, день 2, C&C Family) идут **одним сообщением**: картинка, а текст у неё в подписи, кнопка под ним. Если текст длиннее лимита Telegram на подпись (1024 символа), бот сам отправит картинку отдельно, а текст с кнопкой следом. Приветствие и день 1 работают как раньше: картинка отдельным сообщением перед текстом.

## Хранение данных участников

Прогресс участников хранится в файле `users_state.json`, он создаётся автоматически рядом с ботом. Это простое решение, которого достаточно, пока марафон проходят десятки или пара сотен человек. Если тебе нужно куда более серьёзное хранилище (тысячи участников одновременно), можно потом заменить на базу данных, но пока переусложнять не стоит.

Когда участник доходит до последнего сообщения, администратору приходит уведомление с его именем, username, ID и номером завершившего. Исторический счётчик начинается с 130, если в сохранённых данных нет более высокого значения.

## Ограничения этой версии

- Таймер "24 часа на день" в тексте правил указан для честности перед участником, но сам бот пока не блокирует принудительно доступ по истечении времени (то есть человек физически может писать боту и позже, просто по договорённости мы просим не растягивать). Если нужно сделать именно жёсткую блокировку по времени, это можно добавить отдельно.
- Проверка работы полностью ручная (ты смотришь и жмёшь кнопку), это осознанное решение, а не недоделка, потому что на старте с небольшим числом участников личное внимание куратора работает на доверие лучше, чем полная автоматизация.
- Подписку на TikTok бот проверить не может (у TikTok нет такого доступа для ботов): он проверяет только нажатие кнопки и паузу после него. Заявка в закрытый канал проверяется по-настоящему.
- Бот видит только те заявки, которые пришли, пока он админ канала и запущен. Кто подал заявку раньше, должен отменить её и подать заново (или ты одобряешь такого человека, тогда бот пропустит его как участника канала).
- Цвет кнопок (зелёная ✅ОТКРЫВАЮ, синяя 🎉Итоги) показывают актуальные версии Telegram. В старых приложениях кнопки будут обычного цвета, работают они так же.
- У участников с закрытой приватностью Telegram может не дать сделать кнопку «Написать участнику» по id. Тогда карточка придёт без неё, но с id и @username в тексте.
